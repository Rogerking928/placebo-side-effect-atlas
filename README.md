# Placebo Side-Effect Atlas

Background rates of non-serious side effects in the placebo groups of randomised trials with results posted on
ClinicalTrials.gov (API v2, retrieved 23 October 2026): 100 side effects by condition group and follow-up.

Open the page: https://rogerking928.github.io/placebo-side-effect-atlas/

For each side effect the page shows the mean rate in placebo groups and the 95% prediction interval, the range
expected for the placebo group of a new comparable trial. Trials list non-serious events only above a reporting
threshold (often 5%), so an unlisted event is treated as below that threshold rather than as zero (censored
random-effects model).

These are trial-level background rates, not an individual's risk, and not medical advice. A rate inside or outside
the range does not show whether a drug causes an effect; only a concurrent placebo group can.
